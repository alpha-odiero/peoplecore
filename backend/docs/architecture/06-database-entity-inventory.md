# 06 — Database Entity Inventory

## 0. Conventions

- All identifiers are UUID `[REF]` (UUIDv7 recommended, see D-04). Every table also has `created_at:timestamptz!`, `updated_at:timestamptz!`, `created_by:uuid?`, `updated_by:uuid?`, `version:int!` where mutable — these are omitted from the attribute lists below to keep them readable, except for immutable tables where noted.
- Type notation: `!` = NOT NULL, `?` = NULL allowed. `money:bigint` = integer minor units (e.g. cents); `currency:char(3)` = ISO-4217. `jsonb` used only for configuration/snapshot data, never for relational integrity.
- Every tenant-owned table includes `tenant_id:uuid!` with an index `[REF][BRIEF]`. It is omitted from the attribute list but stated in the **Tenant** column.
- Relationships are 1:N unless stated `1:1`. Self-references indicate hierarchy or replacement chains.
- Classification: **Public** (safe to display), **Internal** (operational), **Confidential** (business-sensitive/PII-lite), **Restricted** (PII, credentials, compensation, legal).
- `[REF]` = PDF-derived, `[BRIEF]` = brief-derived, `[ASSUMPTION]` = added recommendation.
- Immutability is enforced by triggers/grants (doc 09), not only application code.
